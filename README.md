The EE product line running ESDR3 with <a href=https://github.com/ExpertSDR3/TCI>TCI 2.0 </a> (formerly numbered 1.10).

- macOS 13.4 Ventura or later (Silicon and Intel);
- Linux;
- Windows 10/11.
